変更内容
- 「日付・時刻を指定して修正」に「出張」を追加
- 出張は有給と同じく勤務表C列へ表示し、D～N列を空欄化
- 出張日は出勤・退勤の打刻忘れ警告を表示しない
- 出張は有給日数に加算しない
- 通常の即時打刻欄には出張ボタンを追加していない
- 通常の「出勤」ボタンを押すと、同日の出勤・現時刻打刻・有給・出張の修正記録を上書き
- 上書き時の出勤時刻は、登録内容に設定されているその曜日の出勤時刻を使用
- 同日に退勤・途中退社がある場合は残し、新しい出勤時刻を基準に勤務時間を再計算
- 退勤・途中退社の修正記録は、通常の出勤では消さない
- 出勤系は最後の操作が有効（例：修正8:30 → 通常出勤8:00 → 再修正9:00 の場合、最終的に9:00）
