週間出勤状況 修正版 v4

【必ず反映するGitHubファイル】
- schedule-overview.html
- schedule-overview.js
- schedule-overview.css

【必ず反映するApps Script】
- AppsScript-Code.gs をApps Scriptへ全置換
- デプロイを管理 → 既存デプロイを編集 → バージョンを「新バージョン」にしてデプロイ

※今回はApps Scriptの再デプロイが必須です。
※既存デプロイを新バージョンに更新すれば、通常はWebアプリURLは変わりません。

【確認方法】
週間出勤状況ページ上部の緑色メッセージに、以下の人数が表示されれば反映完了です。
月8名 / 火7名 / 水7名 / 木8名 / 金8名 / 土1名 / 日1名

ページ下部のデータ版が以下になっていることも確認してください。
attendance-weekly-overview-v4-20260729-17

【今回の修正】
- Apps Script側で曜日ごとの勤務帯データまで完成させて返却
- 時刻セルをgetDisplayValuesで取得し、Date型・文字列・全角コロンの差を解消
- ブラウザ側も複数の旧データ形式を読み取れるよう互換処理を追加
- PCでは0:00～23:00をページ幅内に全表示
- タブレット・スマホのみ時間軸を左右スクロール
- 「一番上に」「一番下に」は横並びのまま維持

zip内には前回までの全ファイルも同梱していますが、今回の必須更新は上記3ファイルとAppsScript-Code.gsです。
