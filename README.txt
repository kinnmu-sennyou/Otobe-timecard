打刻システム：駐車場・通勤方法管理版 v8

【今回の追加】
1. 新規スタッフ追加フォーム
   - 通勤方法：車 / 徒歩 / 公共交通機関
   - 駐車場番号：1～32（車通勤時のみ）

2. 便利機能
   - 「駐車場使用状況を見る」ボタンを追加
   - parking-status.html へ移動します。

3. 駐車場使用状況ページ
   - 初期表示は当日の曜日
   - 月～日のボタンで切替
   - 駐車場1～32の見取り図
   - 駐車場の週間早見表
   - 徒歩・公共交通機関・通勤方法未登録の表示
   - 既存在籍スタッフの通勤方法・駐車場番号の登録／変更

4. 重複警告
   - 同じ曜日かつ同じ駐車場番号は登録できません。
   - 新規スタッフ登録、既存スタッフの駐車場変更、勤務曜日変更のすべてで確認します。
   - 同じ番号でも勤務曜日が重ならなければ登録できます。

【Apps Script】
AppsScript-Code.gs を全置換し、既存デプロイを「新バージョン」で再デプロイしてください。
再デプロイしないと、駐車場情報の保存・一覧取得・重複警告は動きません。

【スプレッドシート】
Apps Scriptの新版を初めて実行すると、「雇用形態」シートへ以下の列見出しが自動追加されます。
- H列：通勤方法
- I列：駐車場番号

既存スタッフは「駐車場使用状況」ページ下部の編集欄から登録してください。
